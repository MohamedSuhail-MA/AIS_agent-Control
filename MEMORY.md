# MEMORY.md: Project Memory & Status Tracker

## 1. Project Overview & Gold Standard Goals
This repository contains the **Enterprise-Grade Zero-Trust Remote Execution Platform**. It is an orchestration layer and Model Context Protocol (MCP) agent designed to securely bridge cloud-hosted Large Language Models (LLMs) with on-premises Windows infrastructure.

**Gold Standard Objectives:**
- **Zero Trust Network:** No inbound ports opened. Agents poll out via mTLS.
- **Cryptographic Guarantee:** Every job payload is signed via Ed25519 (EdDSA) by the orchestrator. Agents drop tampered or unsigned payloads immediately.
- **Hardware Isolation:** Execution bounded by Windows Job Objects (`KILL_ON_JOB_CLOSE`) to prevent orphan process creep.
- **Semantic Guardrails:** PowerShell Constrained Language Mode (CLM) and Windows Defender Application Control (WDAC) block arbitrary Win32 API access.
- **Observability:** OpenTelemetry `traceparent` headers inject end-to-end traceability from LLM prompt to Windows Event Log.

## 3. Core Architectural Rules (DO NOT BREAK)
1. **Never accept unverified payloads:** `verifyJobPayload` must ALWAYS run before executing a command.
2. **Never expose the orchestrator private key:** The agent must only possess the public key.
3. **Never allow inbound agent connections:** Agents must always `POST /poll`.
4. **Never store non-structural payloads:** Data must strictly adhere to the `toolCallSchema` JSON definition.
5. **Workflow Completion Rule:** "Resume/Go" triggers require Code -> Tests -> Full Test Run Success -> Docs Update -> Docs Verify before responding.
